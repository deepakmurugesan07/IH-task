# React User Dashboard

A simple **React dashboard** displaying users and their posts with **CRUD operations** and **dynamic UI**. Uses local JSON files as data source.

---

## **Features**

- **Users List Page**: shows user cards (Name, Email, Company)  
- **User Detail Page**: user info + list of posts  
  - Add, edit, delete posts (local state)  
  - Pagination with Load More button  
- **Dynamic Navbar**: shows `<User Name> Dashboard` with gradient name  
- Responsive design with custom CSS  
- Loading messages with simulated delay
